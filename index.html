Lua Toolkit / Pastefy

Chọn kiểu xử lý Lua, tải file, tạo Paste và lấy raw URL.

Bảo mật API: Không nhúng API key vào file HTML công khai. Hãy nhập key trong phiên sử dụng và thu hồi/tạo key mới nếu key cũ đã bị chia sẻ. Mọi người có thể xem key khi bạn hard-code nó trong HTML.

01 / Pastefy API

Token chỉ nằm trong ô nhập của trang đang mở; không lưu vào localStorage. Kết nối trực tiếp từ trình duyệt có thể bị CORS hoặc chính sách API chặn.

02 / Nội dung Lua

Chưa có file được đọc.

03 / Chọn xử lý obfuscation

Các chế độ này chỉ là tiền xử lý nhẹ, không phải decompiler/obfuscator chuyên dụng và không đảm bảo tương đương với obfuscator nâng cao. Hãy thử trên bản sao và kiểm tra code trước khi dùng.

04 / Upload lên Pastefy

Lưu ý quyền riêng tư: PRIVATE không đồng nghĩa “chỉ Delta và chủ tài khoản mới xem”. Delta là môi trường chạy script, không phải hệ thống xác thực người xem. Nếu cần giới hạn thật sự, phải xác minh API Pastefy hiện hỗ trợ quyền riêng tư nào; không dùng UNLISTED nếu không muốn bất kỳ ai có link xem được. API v2: POST https://pastefy.app/api/v2/paste. Nếu trình duyệt báo CORS/401, hãy dùng backend riêng để giữ token an toàn.
